Commute Checker Privacy Policy

Last updated August 20, 2026

Commute Checker is a personal Android Auto app (package name com.commutecheck.app) developed by Robert Arne.

Location

The app uses device location to detect nearby saved Places and to request driving times.

Background location is used only for automatic checks triggered by Android Auto / car connection or optional USB power. It is not used for tracking.

Data stored on the device

The following stay on your device:

  • Places
  • Watches
  • Check results
  • Typical-time history
  • Optional Google Maps API key

Data sent off the device

Origin and destination coordinates are sent only to the Google Directions API so the app can request driving times. The app does not send this data to the developer or to any other service.

What the app does not do

  • No account
  • No ads
  • No sale or sharing of location or places with anyone else
